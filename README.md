# Vertral IT — Next.js + Tailwind CSS

A modern, responsive landing page for Vertral IT, built with the Next.js App Router and Tailwind CSS v4.

## Requirements
- Node.js 20.9+
- npm

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

The contact form is UI-only for now. Connect it to an email service, API route, CRM, Formspree, Resend, or another backend before production use.
